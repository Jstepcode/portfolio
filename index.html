Cadence Engine

Multi-VPS deployment platform · Backend & infrastructure contributor

Cadence Engine is a self-hosted deployment platform: you connect a server, pick a project, and it builds, ships and runs the app in Docker containers behind a Caddy reverse proxy, all from one dashboard. Out of the box it ran everything on a single server. I turned it into a multi-server platform, where one control plane manages a fleet of VPS machines ("nodes") and decides where each service should run.

Node detection→Smart routing→Remote deploy→Health check→Live traffic

Stabilising the dashboard

  • Tracked down and fixed a crash that took the dashboard down, and repaired copy buttons that silently did nothing.

Designing the multi-VPS architecture

  • Investigated how the single-server design could scale out, and wrote the plan for a central control plane that talks to remote nodes over SSH.
  • Split the work into two plans: node management first, then a remote deploy system built on top of it.

Plan 1 · Node management Complete

  • Node data model for storing each server's address, credentials and settings.
  • Full create, read, update and delete for nodes from the platform.
  • SSH key pair generation, so the control plane can reach each node securely without passwords.

Plan 2 · Remote deploy system Complete

  • Per-node data directoryEach node stores its app data in its own configurable folder.Done
  • Service routing and eligibility checksDecides which node a service belongs on and whether that node can run it.Done
  • Node-aware deploysThe deploy pipeline targets the chosen node instead of the local machine.Done
  • Image and file transferShips Docker images and project folders to remote nodes.Done
  • Remote container health checksConfirms a container is actually healthy on the node before it takes traffic.Done
  • Rollouts on remote nodesRecreates containers for updates without leaving the service broken.Done
  • Node-scoped Caddy routingEach node's proxy serves only the domains for its own services.Done
  • Node picker when creating a projectLets users choose which server a new project runs on.Done
